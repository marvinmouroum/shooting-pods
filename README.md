# Shooting Pods Berlin 🏀

Interaktives 3D-Konzept: 2 längliche Shooting-Lanes (je ~25 m²) in einem 55-m²-Raum.

- **3D-Modell:** [pods-3d.html](https://marvinmouroum.github.io/shooting-pods/pods-3d.html)
- **Raumplan + Kosten (PDF):** [raumplan-v2.pdf](https://marvinmouroum.github.io/shooting-pods/raumplan-v2.pdf)

Ziehen = drehen · Scrollen = zoomen · Rechtsklick ziehen = verschieben. Maßstab 1:1 (1 Unit = 1 m).
