# Shooting Pods Berlin 🏀

Interaktive 3D-Konzepte: 2 Shooting-Lanes (je 5,3 × 10 m, volle FIBA-Zone) in 132 m² (11 × 12 m).

## Varianten vergleichen

| | Variante A | Variante B |
|---|---|---|
| Ball-Return | Rebound-Maschine (Dr. Dish/Gun, gebraucht) | Fangnetz + Rücklaufschiene + Bowling-Förderer, flacher Boden |
| Modus | Catch & Shoot (Maschine passt) | Self-Shoot (Basis, Rücklauf) + Maschine als Premium |
| Mehrkosten | 2× Maschine ~10.000 € | Rücklaufsystem ~6.000–10.000 € (beide Lanes) + 1 Maschine |
| Störungsanfällig | Maschine = bekanntes Produkt | Förderer = Eigenbau, mehr Wartung |

- **Variante A:** https://marvinmouroum.github.io/shooting-pods/pods-3d-a.html
- **Variante B (Ballrücklauf):** https://marvinmouroum.github.io/shooting-pods/pods-3d-b.html
- **Raumplan + Kosten (PDF):** https://marvinmouroum.github.io/shooting-pods/raumplan-v2.pdf

Ziehen = drehen · Scrollen = zoomen · Rechtsklick = verschieben. Maßstab 1:1 (FIBA-Maße).
